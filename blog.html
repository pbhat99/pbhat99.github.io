ComfyUI Portable with Production Custom Nodes

Download and extract the latest standalone portable release from GitHub:
https://github.com/comfyanonymous/ComfyUI/releases

Essential Production Custom Nodes:

Navigate to ComfyUI/custom_nodes/ and clone the essential toolsets:

1. ComfyUI Manager: 
git clone https://github.com/ltdrdata/ComfyUI-Manager comfyui-manager
2. RGThree (Workflow Routing & Mute Bypasses): 
git clone https://github.com/rgthree/rgthree-comfy.git
3. Video Helper Suite (VHS): 
git clone https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite.git
4. CrysTools (Resource Monitor HUD): 
git clone https://github.com/crystian/comfyui-crystools.git
5. Procedural & Advanced Math Nodes: 
git clone https://github.com/melMass/comfy_mtb.git
git clone https://github.com/kijai/ComfyUI-KJNodes.git

git clone https://github.com/chrisgoringe/cg-use-everywhere

Steps to Install FaceFusion 3 on Windows (Portable)

Clean portable setup using isolated Python virtual environments: 

git clone https://github.com/FaceFusion/FaceFusion.git
cd FaceFusion
python -m venv myenv
myenv\Scripts\activate
python install.py --onnxruntime cuda

Launch the interactive GUI: 

python facefusion.py run
